# 全局设置与编辑弹窗：大弹层、铃声与图片导入

[阶段 1 导航](README.md) · [启动方式（CMD）](mvp.md#现在怎么启动cmd) · [后续部署路线](../common/deployment-route.md)

## 本次实现

登录后点击右上角齿轮“设置”，只调整两个全局通道：到期播放提示音、电脑桌面通知。
保留“恢复声音”与桌面权限申请/测试按钮，避免把开关已保存误认为音频或系统通知已可用。
选择铃声、音量、提醒样式、插画、导入/移除素材、试听/停止和预览，全部移至备忘录编辑弹窗。
从主页点击备忘录或“新建备忘录”即可看到，首页不铺开选项。
大弹层只在网页内展示，不覆盖其他软件，不改变操作系统通知的尺寸。

本次只调整入口与错误交互，沿用当前账号在此浏览器共用的一套样式、铃声与导入副本，修改后自动保存。
**尚未改成每条备忘录独立选择**；已询问用户，待确认后再单独实现，不把 UI 移动冒充单条配置或云端同步。
标题、正文和提醒时间现由底栏一个“保存”统一提交，新建时即可设时间，见 [统一保存与声音诊断](unified-save.md)。
上述浏览器偏好/素材仍修改即保存，不冒充已参加数据库事务或已实现单条配置。

内置选项全部保留：铃铛/备忘录两种插画、不显示插画，以及清脆双音/柔和三音/明亮提示三种铃声。
内置插画是工程内 SVG，铃声由 Web Audio 合成，无需下载素材。

新增“导入图片”“导入铃声”，导入成功后自动选择对应自定义选项，可随时切回内置选项。
每个账号在当前浏览器各保存一份图片、一份铃声；再次导入替换该类型的副本，不修改磁盘原文件。
图片用于网页大弹层；不把自定义图片强行塞进 Windows 系统通知。

| 文件 | 支持范围 | 限制 |
| --- | --- | --- |
| 图片 | PNG、JPEG、WebP | 非空、最多 2 MiB；宽高各不超过 4096，总像素不超过 1200 万。 |
| 铃声 | MP3、WAV、OGG，且当前浏览器可解码 | 非空、最多 5 MiB；时长大于 0 且不超过 60 秒；单次播放、不循环。 |

先核对真实文件头，再用浏览器解码检查；不接受 SVG/HTML、任意网址或只修改后缀伪装的文件。
文件选择框旁常驻显示可选扩展名、格式与大小/尺寸/时长限制，文件输入的 accept 过滤不代替真实格式校验。
解码失败、超时或存储失败在对应导入按钮旁显示错误，编辑弹窗保持打开，保留原有副本、选择、标题/正文及提醒时间，允许直接重试。
取消选择或重选同一文件也不能关闭编辑：文件输入的 cancel 会冒泡，原处理将其误当作 dialog 的 Esc；
现在仅接受来源为 dialog 自身的取消事件，见 [MDN 文件输入 cancel 事件](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/cancel_event)。
自动测试验证事件区分与错误保留，但本轮实际浏览器运行时启动失败，不能断言已在用户浏览器复现全部原因。
试听不自动开启到期声音，导入也不自动播放。
“停止播放”停止当前声音，不关闭到期声音开关；关闭声音开关则停止并禁用后续到期声音。

## 保存在哪里

- `localStorage` 只保存按账号区分的非敏感偏好白名单：样式、插画、铃声、音量与声音/桌面开关。
- IndexedDB 只保存导入文件的浏览器副本与必要元数据，按账号和文件类型分别读取。
- 不上传文件，不保存磁盘路径、密码、会话 Cookie、CSRF 或备忘录内容；不新增数据库表或上传接口。
- 退出清除当前页面的播放器、图片地址和提醒内容，但保留该账号的浏览器偏好/副本，下次登录可加载。
- “移除导入副本”只删除当前账号在此浏览器的对应副本；其他账号副本、磁盘原文件和内置选项不受影响。

这是界面读取时按账号区分，不是对浏览器本地文件进行加密；共用电脑的其他使用者可能通过开发工具查看本地存储，
不要导入敏感内容。清理浏览器数据、隐私窗口结束、存储被回收或换设备会导致副本丢失，不作为文件备份。
同一账号换浏览器/设备不会同步这些偏好；从 localhost 换成正式 HTTPS 域名也不会自动迁移，届时需重新设置/导入。
浏览器存储按来源区分，见 [MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)。

保存声音开启偏好不等于浏览器已允许播放。刷新后不自动响铃；已开启时点击“保存”会尝试恢复，
也可在设置或编辑点击“恢复声音”。主页和编辑显示未激活/音量零/开关关闭/播放失败等状态，试听不自动开启开关。
桌面通知已有授权时可恢复开启偏好；没有授权时不会自动弹权限窗口，只在用户点击时申请。
实际声音/系统弹窗仍受浏览器、音量和系统设置影响，见 [Chrome 自动播放策略](https://developer.chrome.com/blog/autoplay/)。

## 大弹层与已读的关系

首次加载的历史未读仍显示常驻卡片，不突然补弹大窗口或补响铃。
选择大弹层后，新发现提醒进入待处理队列；多个提醒显示当前一条和数量，标为已读后可处理下一条。
关闭真实大弹层只收起本次队列，不标为已读；查看备忘录也不自动已读。
预览叠在编辑弹窗之上，不关闭或重填编辑；关闭/Esc 返回原草稿，预览不写通知、不播放声音、不清空真实待处理队列。
设置、编辑或回收站打开、页面隐藏或正在操作时不抢真实大弹层，关闭弹窗/切回页面/操作结束后再展示待处理提醒。
支持关闭按钮与 Esc；使用原生 dialog 模态焦点行为，见 [MDN dialog](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)。

页面内去重和收起状态仍只存本次登录内存，不跨标签页协调。常驻卡片、通知已读和调度事务逻辑沿用原实现。
网页须保持打开，服务端须运行；关闭网页、休眠或手机锁屏暂无可靠实时推送，不把大弹层称为 Web Push。

## 网页验收

无需逐接口输入命令；如需启动，使用上面的现有 CMD 启动说明，不重复建表。

1. 重启应用、Ctrl+F5 刷新页面、登录。右上角齿轮只见声音/电脑桌面两类全局设置，不含样式/铃声/导入选项。
2. 关闭设置，点击备忘录或新建，确认样式、铃声、音量和导入都在编辑弹窗，支持主体滚动与底栏操作。
3. 输入未保存文字及提醒时间，切换插画、预览大弹层；关闭或 Esc 后仍是原编辑内容，未读数不变。
   试听三种内置铃声、调音量、停止，试听不自动开启到期声音。
4. 导入一张符合限制的个人图片，预览能看到图片；再切回铃铛，确认内置插画没有删除。
5. 导入一段符合限制的短铃声，试听、停止、调音量；启用到期声音，必要时点击“恢复声音”。
6. 图片旁提示 PNG/JPEG/WebP，铃声旁提示 MP3/WAV/OGG。尝试损坏、不支持或过大文件，错误应在对应导入处显示。
   编辑不能退出，标题/正文/提醒时间与之前可用副本不变；直接更换文件可重试。
   再打开文件选择器点取消、按 Esc 或重选同一文件，不能将编辑弹窗一起关闭。
7. 刷新并登录，打开编辑可看到恢复的选择与副本；查看声音状态，已开启时点击保存可尝试恢复，失败可手动恢复。
8. 新建专用测试备忘录，设置约一分钟后提醒，关闭编辑但保持网页打开。确认大弹层、卡片与选定铃声；
   后端 5 秒扫描、前端 10 秒尝试检查，并非绝对准点。关闭大弹层仍未读，标为已读后才消失。
9. 再次导入替换副本；点击移除，确认恢复内置选择，磁盘原文件没有删除。换另一个测试账号不显示前一账号副本。
10. 桌面通知继续按 [主动提醒验收](active-reminders.md#网页验收不需要逐接口输入命令) 单独确认。

只对新建的测试记录做删除验收，保留学习账号与原有备忘录。

## 代码与自动验证

- `reminder-preferences.js`：偏好白名单、版本和账号键、不可用存储回退。
- `reminder-assets.js`：文件头/解码/限制、IndexedDB 副本、对象地址生命周期。
- `reminder-alerts.js`：三种内置铃声、导入铃声播放/停止、大弹层队列、偏好与实际授权状态分离。
- `app.js`、`index.html`、`styles.css`：全局设置与编辑选项分开，导入就地反馈、文件取消来源保护、叠层预览与草稿保留、窄屏布局及账号清理。
- `SecurityConfiguration`：只公开新增脚本的 GET；仅图片/音频允许本地 Blob 地址，脚本仍只允许同源，API 认证/CSRF 不放宽。

最新离线 Java 报告 294 项：284 通过、10 项真实 MySQL 默认跳过；统一保存另单独通过 4 项真实 MySQL 验收，临时数据已清理，学习数据保留。
前端 80 项通过，包括选项分区、格式提示、预览草稿、取消冒泡、导入失败、统一保存及到期声音状态，详见统一保存文档。
前端使用已有 Node 内置测试与 DOM/存储/解码替身，**不是实际浏览器编解码、持久化、扬声器、系统通知或手机实测**。
