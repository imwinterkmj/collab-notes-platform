齿轮只放声音/电脑桌面全局开关，样式、选铃声、素材导入与试听/预览移入编辑；内置选项保留，当前仍是账号共用偏好，副本暂不跨设备同步。
主页未完成优先，再按更新时间排序；点击打开编辑弹窗，删除记录可从最近 30 条回收站恢复，旧提醒不恢复。
新建即可填提醒时间，内容和提醒在一个事务保存；声音开关与播放器状态分开，已开启时保存尝试恢复播放，试听不自动打开开关。
尚不包含关页/锁屏推送、离线同步或编辑冲突合并；App 前台现自动同步，网页列表仍手动刷新。
通知不再主动因切到后台停查，切回立即补查，但浏览器后台节流仍可能延迟。基础网页验收通过，后续仍需工程收尾与复盘。

`http/` 下只保存公开学习示例，禁止放入真实密码、Cookie 或 CSRF token。
